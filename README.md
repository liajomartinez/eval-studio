# Eval Studio

Eval Studio takes a description of a government AI pilot — its context and its
evaluation results — and returns a reasoned readiness determination: **ready
to scale**, **not ready**, or **conditionally ready**. It cites which specific
criteria passed or failed, and abstains when there isn't enough information to
judge.

This is a work in progress, built in the open. See [SPEC.md](SPEC.md) for the
tool's design.

## Status

Early development. Not yet functional end to end.
